# Ayushi Agrawal Portfolio

React, Vite, Tailwind CSS, TypeScript, GSAP, Framer Motion, and hls.js portfolio site.

## Local development

```bash
npm install
npm run dev
```

## GitHub Pages deployment

This repository is configured to deploy the production Vite build to GitHub Pages with GitHub Actions.

After pushing to `main`, go to the repository on GitHub:

1. Open `Settings`.
2. Open `Pages`.
3. Under `Build and deployment`, set `Source` to `GitHub Actions`.
4. Wait for the `Deploy portfolio to GitHub Pages` workflow to finish.

The site will publish at `https://ayushivagrawal.github.io/`.
